# Covers for the World English Bible verse cards

The fifteen files here are the SOURCES. What ships is in `public/assets/verses`,
resized to a 1920 long edge and re-encoded at quality 58 — that lands every card
between 58 and 238 KB per megapixel, inside the 52-295 the existing covers
already span. Originals are kept at full size so a cover can be re-encoded
without going back to Pinterest.

Sourced off Pinterest, so provenance is recorded. Nothing here has a stated
licence; the pin pages carry no rights information and several are re-pins of
re-pins. Recorded so the question stays answerable, not because it is answered.

The style brief came from the covers already shipping rather than from a fresh
idea: a solitary figure, small, in a vast landscape under a dramatic sky,
painted rather than photographed. The query that found this set is the one that
had already been validated against the existing art — it returned four images
that were ALREADY in art-candidates/, which is how the register was confirmed.
Literal searches ("stone tower", "fortress") were tried first and discarded:
they return castles, and a "strong tower" drawn as an actual castle is clip-art.
